# iris-flower-classification
# 🌸 Iris Flower Classification

## 📌 Overview

This project uses a neural network to classify iris flowers into three species:

* Setosa
* Versicolor
* Virginica

---

## 🧠 Model

* Deep Learning Model (TensorFlow/Keras)
* Dense Neural Network
* Softmax output layer

---

## ⚙️ Tech Stack

* Python
* TensorFlow
* NumPy, Pandas
* Matplotlib, Seaborn

---

## 🚀 Workflow

1. Load dataset
2. Encode labels
3. Train neural network
4. Evaluate accuracy
5. Predict new samples

---

## 📊 Results

* Achieves high accuracy (~95–100%) on Iris dataset

---

## ▶️ How to Run

```bash
pip install tensorflow numpy pandas matplotlib seaborn scikit-learn
python iris_model.py
```
